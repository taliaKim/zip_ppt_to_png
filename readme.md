
방과후 강사들을 위한 프로그램

과제물 회수 프로그램으로 여러 개의 ppt 파일을 받을 때 압축파일로 컴퓨터에 저장된다.

이 때, ppt 파일을 일일이 열지 않고 위 프로그램을 다운받아 압축을 풀어 실행하면 자동으로 png 파일로 변환된다.

압축 파일 이름이 학생01.zip 이렇게 들어오기 때문에 학생 이름 엑셀 파일을 첨부하면 이름을 파일 이름에 붙여 이미지로 생성된다.

ppt의 원하는 슬라이브 번호나 범위를 선택하여 이미지로 바꿀 수 있다.

단, 반드시 프로그램을 시작하기 전, ppt를 먼저 실행하여 새 파일을 하나 만들어 놓고 프로그램을 시작하도록 한다.

만들어진 이미지 파일은 압축파일이 있는 폴더에 같이 만들어진다.
